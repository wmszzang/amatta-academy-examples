## 흔한 실점

- 이동을 먼저 하고 회전하면 둘째 점이 `(1.7039, 0.7048)`로 어긋납니다. 순서는 회전 → 이동입니다.
- 역변환 이동항은 `-t`가 아니라 `-Rᵀt`입니다. 변환의 역은 역기구학이 아닙니다.
- 두 프레임의 이동량을 그대로 더하거나 `T_BC·T_AB`로 순서를 뒤집으면 오답입니다. 행렬 곱은 비가환입니다.
- 두 번째 관절각은 상대각입니다. 바닥 기준 방향은 누적각 `θ1+θ2`입니다.
- "DH로 유도"가 조건이면 링크별 `A_i` 행렬을 만들어 곱한 과정까지 제출합니다. 끝점만 맞히면 유도 점수를 놓칩니다.
- 스윕은 `0도`와 `90도`를 모두 포함해 7행입니다.
- 각도 복원은 소수 4자리로 반올림한 점이 아니라 변환 결과 값 그대로에서 하세요. 반올림한 `(1.5830, 0.2883)`으로 atan2를 취하면 `34.9998`이 나옵니다.
- 헤딩 평균은 산술평균이 아니라 `atan2(Σsin, Σcos)`입니다.
