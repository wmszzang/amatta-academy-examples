# EP.7 — 2·3링크 순기구학

관절각은 각 링크의 상대각입니다. `fk()`는 각도를 누적한 뒤 링크의 가로·세로 성분을 더해 베이스부터 손끝까지의 관절 좌표를 반환합니다.

| 입력 | 기대 끝점 |
|---|---|
| θ=(30,45), l=(1.5,1.0) | (1.5579, 1.7159) → (1.56, 1.72) |
| θ=(15,20,30), l=(1.5,1.2,0.8) | (2.7700, 1.8016) → (2.77, 1.80) |

```powershell
python python/fk_arm.py
gcc c/fk_arm.c -o fk-c.exe -lm; .\fk-c.exe
g++ -std=c++11 cpp/fk_arm.cpp -o fk-cpp.exe; .\fk-cpp.exe
```

흔한 실점은 두 번째 각도에 `θ2`를 그대로 넣는 것입니다. 바닥 기준 방향은 항상 누적각 `θ1+θ2`입니다. `python/visualize.py --frames`는 관절 점과 등축척 스틱 다이어그램을 만듭니다.
