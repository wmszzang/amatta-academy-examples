## 일곱 유형 판별표

| 유형 | 지문 신호어 | 계산 순서 | 주의할 조건 |
|---|---|---|---|
| 운동계획 | 최고속도, 가속도, 시간 그래프 | 가감속 거리 비교 → 구간 시간 → 위치·속도 | 짧은 거리의 삼각형 분기 |
| 좌표 변환 | 점 목록, 회전, 이동, 기준 | 회전 후 이동, 기준 연결 | 순서와 단위 |
| 순기구학 | 링크 길이, 관절각, DH | 누적각 또는 표준 DH 체인 | 상대각·절대각 구별 |
| 역기구학 | 목표점, 관절각, 초기각 | 도달성 → 해 → 선택 → FK 복원 | 두 분기·도달 불가 |
| 자코비안 | 관절속도, 손끝속도, 특이점 | 자세별 변화율 표와 관절속도 곱 | 위치와 속도의 구별 |

| 위치 추정 | 바퀴 기록, 측정, 보정 | 이동 예측 → 측정 보정 | 위치와 분산 함께 갱신 |

좌표 변환과 FK 예제의 길이 단위는 원문에서 지정하지 않았습니다. 임의로 미터를 붙이지 않습니다.

```text
0 0 0 0
1 1 0 1
0 0 0 0
0 1 1 0
```

`0=통행`, `1=장애물`, 좌표는 `(행,열)`입니다. 경로는 `(0,0)→(0,1)→(0,2)→(1,2)→(2,2)→(2,3)→(3,3)`입니다. 검산 코드는 단위 비용 격자의 너비 우선 탐색으로 경로를 독립 복원합니다. 강의의 A* 최단경로 결과와 비용 하한을 대조하는 용도입니다.

각 실행은 유형·입력 식별자, 계산값, `PASS` 순서로 콘솔과 `crash_check.csv`를 만듭니다. 내부는 배정밀도이며 출력할 때만 소수 10자리로 반올림합니다. 독립 기대값과 절대 오차 `1e-8` 이내인지 검사하고, 실패하면 종료코드 1로 끝납니다. CSV 행의 값 순서는 위 표와 같습니다. 2차 칼만 출력은 위치, 분산 순서입니다.

## 설치·컴파일·실행

Python 3 계산 코드는 표준 라이브러리만 사용합니다. 그림 생성에만 Matplotlib을 설치합니다.

```powershell
cd python
python crash_check.py
python -m pip install matplotlib
python visualize.py
python visualize.py --frames
```

`crash_check.png`는 정적 계산 결과입니다. `frames/frame_000.png`부터 48장은 12fps로 재생할 수 있습니다. 기존 FK 입력의 각도까지 선형 보간한 자세 그림이며, 축 비율을 고정했습니다. 힘·질량·모터 성능을 계산하는 동역학 시뮬레이션은 아닙니다.

```powershell
cd c
gcc crash_check.c -o crash_check.exe -lm
./crash_check.exe
```

```powershell
cd cpp
g++ -std=c++11 crash_check.cpp -o crash_check.exe
./crash_check.exe
g++ -std=c++11 plot_svg.cpp -o plot_svg.exe
./plot_svg.exe
```

각 명령은 에피소드 폴더 기준이며, 다른 언어로 이동할 때는 상위 폴더로 돌아옵니다. C++ 검산 코드는 C와 같은 수식을 사용해 언어별 실행 결과를 비교하며, `plot_svg.cpp`는 표준 라이브러리만으로 `crash_check.svg`를 직접 만듭니다.

## 검산 6종과 경계 실험

1. 도·라디안: 30°는 약 0.5236 rad. 삼각함수 입력과 역삼각함수 출력의 단위를 구분합니다.
2. 각도 래핑: 목표 3 rad, 현재 -3 rad의 최단 차이는 -0.2831853072 rad입니다. 다회전 명령에는 무조건 래핑하지 않습니다.
3. 곱 순서: (1,0)을 회전 후 이동하면 (1.8660,1.0000), 이동 후 회전하면 (1.4821,1.4330)입니다. 열벡터에서는 오른쪽부터 적용합니다.
4. DH 부호: 표준 `Rz(theta) Tz(d) Tx(a) Rx(alpha)`와 직접 FK를 대조합니다. 수정 DH와 섞지 않습니다.
5. 속도 분기: D=1일 때 꼭대기 속도 1·총 2초, D=4일 때 등속시간 0·총 4초입니다. D=10의 t=6.75에서 위치 9.96875·속도 0.25이므로 종료점 t=7을 빠뜨리지 않습니다. 기존 #119 표는 마지막 행의 가속도를 감속 구간 -1로 기록하고 이후 정지 구간 0과 구별합니다.
6. acos·atan2: 사인 부호 두 분기를 만들고 `atan2(y,x)`의 입력 순서를 확인합니다. (0,0)의 방향은 정해지지 않습니다. 도달 불가 목표를 억지로 범위에 끌어넣지 않습니다.

각 실험은 기존 입력을 바꾸기 전에 출력 규약과 기대값을 함께 정합니다. 프로그램이 실행됐다는 사실만으로 정답으로 판단하지 않습니다.
