# EP.29 종합 모의 — 궤적 그래프와 좌표 변환

서로 독립된 실기 연습장 #119와 #226을 연결한 학습용 예제입니다. 공식 기출 원문이나 공식 모범답안의 재현이 아닙니다. Python은 목록, C는 동적 배열과 원소 수, C++는 `vector`로 계산 결과를 반환합니다. 저장·화면 출력·그리기는 반환값을 받은 다음 수행합니다.

## 입력과 계산

### #119 사다리꼴 속도 운동계획

거리 D=10 m, 최고속도 V=2 m/s, 가속도 크기 A=1 m/s², dt=0.25 s입니다. 시작과 종료 속도는 0입니다.

1. 가속시간 V/A=2 s, 가속거리 V²/(2A)=2 m를 구합니다. 감속거리도 2 m입니다.
2. 등속거리 6 m, 등속시간 3 s입니다. 가속 종료 2 s, 감속 시작 5 s, 종료 7 s입니다.
3. 가속 구간은 x=0.5t², v=t, a=1입니다. 등속 구간은 x=2+2(t-2), v=2, a=0입니다. 감속 구간은 x=10-0.5(7-t)², v=7-t, a=-1입니다.
4. 종료 시각을 포함해 29행을 반환합니다. 시간 간격이 나누어떨어지지 않을 때도 종료점을 한 번만 추가합니다. 반복 적분으로 근사하지 않고 구간식을 직접 평가합니다.

| t (s) | x (m) | v (m/s) | a (m/s²) |
|---:|---:|---:|---:|
|0|0|0|1|
|1|0.5|1|1|
|2|2|2|0|
|3|4|2|0|
|5|8|2|-1|
|6|9.5|1|-1|
|6.75|9.96875|0.25|-1|
|7|10|0|-1|

운영 기대표는 정확히 t=7에서도 감속 쪽 값 a=-1을 적습니다. 종료 뒤 정지 구간 t>7을 그린다면 a=0입니다. 마지막 행의 약속을 종료 이후로 연장하지 않습니다.

### #226 2D 강체 변환 — 정점 좌표

정사각형 A(0,0), B(1,0), C(1,1), D(0,1)을 원점 기준 반시계 30° 회전하고 (1,0.5)만큼 이동합니다. 원문은 길이 단위를 지정하지 않으므로 m를 붙이지 않습니다.

- 30° = π/6 rad. c=cos(π/6), s=sin(π/6).
- x′=cx-sy+1, y′=sx+cy+0.5. 원본 x,y를 함께 사용합니다.
- 원본과 결과 좌표를 `points.csv`에 기록하고 네 점만 반환합니다. 그림을 닫을 때만 A를 재사용합니다.

|정점|회전만 적용|이동까지 적용|
|---|---|---|
|A|(0,0)|(1.0000,0.5000)|
|B|(0.8660,0.5000)|(1.8660,1.0000)|
|C|(0.3660,1.3660)|(1.3660,1.8660)|
|D|(-0.5000,0.8660)|(0.5000,1.3660)|

표시만 반올림합니다. 계산은 언어의 배정밀도를 유지합니다. 이동부터 한 뒤 회전하면 B는 (1.4821,1.4330)이 되어 요구와 다릅니다. 역변환은 이동량을 먼저 빼고 시계 방향 30° 회전합니다. 네 변의 길이는 모두 1이지만, 길이 검사만으로 위치·순서의 정답을 보장하지는 못합니다.

## 설치와 실행

Python 3, GCC 또는 Clang의 C 컴파일러, C++11 이상 컴파일러가 필요합니다. Python 계산에는 표준 라이브러리만 사용합니다. 시각화는 `python -m pip install matplotlib numpy`로 설치합니다. 각 언어 폴더에서 실행하면 `trajectory.csv`와 `points.csv`를 생성합니다.

```powershell
cd python
python mock_walkthrough.py
python visualize.py
python visualize.py --frames
```

`result.png`는 세 시간 그래프와 동일 배율의 좌표 그래프입니다. `--frames`는 `frames/frame_000.png`부터 36장을 만듭니다(12fps로 3초). 그래프는 실제 CSV를 읽습니다.

```powershell
cd c
gcc mock_walkthrough.c -o mock_walkthrough.exe -lm
./mock_walkthrough.exe
```

```powershell
cd cpp
g++ -std=c++11 mock_walkthrough.cpp -o mock_walkthrough.exe
./mock_walkthrough.exe
g++ -std=c++11 plot_svg.cpp -o plot_svg.exe
./plot_svg.exe
```

`result.svg`를 브라우저로 열면 C++가 CSV에서 직접 그린 그래프를 봅니다. 세 언어 출력은 소수 10자리로 맞췄습니다. C가 반환한 두 배열은 호출자가 `free()` 해야 합니다.

## 추가 경계 입력과 검산

아래는 원문 예시가 아닌 학습용 추가 입력입니다. V=2, A=1을 유지합니다.

|거리|프로파일|꼭대기 속도|총시간|dt=0.25 행 수|
|---:|---|---:|---:|---:|
|1|삼각형|1|2|9|
|4|등속시간 0인 경계|2|4|17|
|10|사다리꼴|2|7|29|

Python: `python mock_walkthrough.py --distance 1`; C/C++: `./mock_walkthrough.exe 1`. 종료점 추가 실험은 Python의 `--distance 10 --dt 0.3`, C/C++의 `10 0.3` 인자입니다(25행, 마지막 간격 0.1초). 양수가 아닌 입력은 거부합니다.

검증한 항목: 기본 입력 전 행·2/5/7초 경계, 삼각형과 경계 입력, 나누어떨어지지 않는 간격, 네 정점, 역변환 복원, 네 변 길이, 세 언어 CSV·표준출력 일치. 운영 기대표의 표시 반올림은 허용오차 0.000051로 비교했습니다.

흔한 실점: 마지막 행 누락, 감속 가속도를 종료 뒤까지 유지, 도를 그대로 삼각함수에 전달, 이동·회전 순서 뒤집기, 원본 x를 덮어쓰기, 좌표 그래프 축 배율 불일치, 화면 출력만 하고 목록 반환을 빠뜨리기.
