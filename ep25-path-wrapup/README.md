# EP.25 경로계획 끝내기 — 지문으로 풀이 고르기

자체 실기 연습문항과 강의용 확장 예제입니다. 공식 기출 재현이나 실제 장비 제어 코드가 아닙니다.

| 입력 | 계산 | 기대 결과 |
|---|---|---|
| `[[1,3,1],[1,5,1],[4,2,1]]` | 시작 칸을 포함한 다익스트라 | 최소비용 7 |
| `[[0,0,0,0],[1,1,0,1],[0,0,0,0],[0,1,1,0]]` | 네 방향 A*, 시작 `(0,0)`, 목표 `(3,3)` | 좌표 7개, 이동·비용 6 |
| 아래 고정 표본, 금지 원판 중심 `(2,0)`, 반지름 1 | RRT* | `S→N→G`, 길이 4.664761516 m |
| 후보 `(0.5,0),(0.5,0.3),(0.3,0)`, 거리 `2,1.5,2.5` | #401 평가함수 | 셋째 후보, 0.793333333 |
| `[[0,0,0],[0,1,0]]` | 경운 방문 목록 + BFS 연결 | 대상 5개, 위치 기록 8개, 이동 7회 |

표본은 `(4,0),(0,2),(2,2),(4,2),(4,0),(4,-1),(2,1.2)` 순서이며 세 언어가 동일 목록을 사용합니다. 범위는 x=-1~5, y=-1~3, 확장 길이와 이웃 반경은 3 m입니다. 최근접점과 부모 비용 동률은 먼저 삽입된 점이 이깁니다. 접촉도 충돌로 거부합니다. 목표 발견 후에도 끝까지 개선합니다. 이 유한 표본 결과는 연속 공간 최단경로 증명이 아닙니다.

## 설치와 실행

Python 3.8 이상(시각화는 matplotlib 필요), GCC와 C++11 컴파일러를 사용합니다. 예제 디렉터리에서:

```sh
python python/path_wrapup.py
python -m pip install matplotlib
python python/visualize.py
python python/visualize.py --frames
gcc c/path_wrapup.c -o path_wrapup_c -lm
./path_wrapup_c
g++ -std=c++11 cpp/path_wrapup.cpp -o path_wrapup_cpp
./path_wrapup_cpp
g++ -std=c++11 cpp/plot_svg.cpp -o plot_svg
./plot_svg
```

Windows에서는 실행 파일 이름에 `.exe`를 붙입니다. C++는 C와 호환되는 계산 코어를 include하여 같은 규약을 사용합니다. Python은 별도 구현입니다. 세 언어 stdout은 동일한 CSV 형식이며 실행 시 경계조건 assert도 검사합니다. C++ SVG와 Python PNG·프레임은 실제 좌표와 부모 장부에서 생성합니다. 생성 파일은 커밋하지 않습니다.

## 구현과 검증

다익스트라·A*는 최소 `(f,g,행,열)`을 선택하며 비용과 부모를 함께 갱신합니다. C 코드는 작은 고정 지도에 맞춰 최소 후보를 선형 탐색하고 Python은 heap을 사용합니다. A* 맨해튼 거리는 네 방향 단위비용 조건에만 적용합니다.

선분 검사는 투영 비율을 0~1로 제한하고 길이 0 선분을 점 거리로 처리합니다. RRT*는 부모 선택, 엄격한 비용 감소 재연결, 순환 방지, 자손 비용 전파를 수행합니다. 최종 부모 장부 비용과 복원 경로의 구간 길이 합을 직접 대조합니다. D 비용은 4.486446681, G는 4.664761516, E는 5.664761516입니다. N→E 직접 연결은 장애물 중심과 거리 0.807207353으로 거부됩니다.

#401은 위치를 먼저 갱신하는 전진 오일러 한 단계 근사입니다. `H=1/(1+|방향차|)`, `V=v`, `C=min(d/3,1)`, `G=0.4H+0.2V+0.4C`입니다. 원문 예시 답 `(0.5,0)`과 달리 원문 수치를 그대로 계산하면 `(0.3,0)`이 최고점입니다. 이 함수만으로 동적 창·제동 안전을 검사했다고 주장하지 않습니다.

별도 보충 계산: 현재 v=0.4, w=0, dt=0.1, 가속도 한계 2·3, 기계 범위 v=[0,1], w=[-1,1]이면 동적 창 v=[0.2,0.6], w=[-0.3,0.3]입니다. 지연 없는 직진 일정감속에서 v=0.6, a=1이면 정지거리 0.18 m로 남은 0.15 m보다 커 거부합니다.

## 실험과 흔한 실점

- A* 지도의 `(1,2)`를 막으면 `NO PATH`: 격자 탐색을 소진했습니다.
- 첫 표본 하나만 처리하면 `NOT FOUND`: 유한 표본으로 미발견이며 경로 부재 증명이 아닙니다.
- 빈 속도 후보는 `NO CANDIDATE`입니다. 실제 장비의 즉시 안전 정지를 보증하는 반환값이 아닙니다.
- `[[0,1,0]]`의 반대편 자유 칸은 `UNREACHABLE`입니다. 직선으로 채우지 않습니다.
- 시작=목표, 길이 0 선분, 원 접촉, 중복 표본, 장애물뿐인 지도도 검사합니다.
- 시작 비용 누락, 부모만 바꾸고 자손 비용 방치, 반올림값으로 충돌·점수 판정, 방문 목록을 주행 경로로 오인하는 실수를 피합니다.
