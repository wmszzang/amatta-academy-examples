# EP.11 — 자코비안과 특이점

관절 하나를 움직일 때 생기는 손끝 속도 화살표를 열로 모아 자코비안을 만들고, 연습장 #239를 계산합니다. C·C++·Python 계산 프로그램은 같은 CSV·텍스트를 만듭니다(운영체제별 줄바꿈 제외).

## 입력과 계산

`jacobian`의 입력 길이는 m, 관절각은 rad입니다. `ee_vel`의 관절속도는 rad/s, 결과는 m/s입니다. 예제 실행의 고정 입력은 다음과 같습니다. 다른 자세를 실험하려면 각 언어의 `main`에 있는 호출 인자를 바꾸세요.

| 입력 | 값 |
|---|---|
| a1, a2 | 2.0, 1.5 m |
| theta1, theta2 | 0.5236, 0.7854 rad |
| 관절속도 d1, d2 | 0.1, 0.2 rad/s |

30도·45도는 설명용 근삿값입니다. 계산에는 위 소수를 그대로 넣고 중간 결과는 반올림하지 않습니다.

```text
J = [[-a1*sin(t1)-a2*sin(t1+t2), -a2*sin(t1+t2)],
     [ a1*cos(t1)+a2*cos(t1+t2),  a2*cos(t1+t2)]]
v = J * qdot
det(J) = a1*a2*sin(t2)
```

| 결과 | 기대값 |
|---|---|
| 제출 출력 | `-0.5347 0.2897` |
| 행렬 J, 첫째 행 | -2.4488920485, -1.4488899278 |
| 행렬 J, 둘째 행 | 2.1202737158, 0.3882241326 |
| 행렬식 | 2.1213 |
| 말단 속력 | 0.6081 m/s |
| 방향 | 가로 양의 방향에서 반시계 151.6도 |
| 각 열의 길이 | 3.2392, 1.5000 m/rad |

`joint_vel`은 정방 2×2 행렬의 역행렬 공식을 적용합니다. `abs(det)<1e-6`이면 Python은 `None`, C·C++은 성공 여부 0을 반환합니다. 이 임계는 작은 분모를 피하기 위한 **이 예제의 수치 기준**입니다. 로봇의 보편적인 안전 기준이나 특이점의 정의가 아닙니다.

## 설치·실행

Python 계산은 표준 라이브러리만 사용합니다. Python 3.10 이상을 권장하며, 시각화에는 NumPy·Matplotlib이 필요합니다. 아래 명령은 이 에피소드 폴더에서 실행합니다.

```powershell
python python/jacobian.py
python -m pip install numpy matplotlib
python python/visualize.py --arrows --sweep --wrist --out output
python python/visualize.py --arrows --sweep --wrist --frames --out output
```

`--arrows`는 두 열과 평행사변형, `--sweep`은 각도에 따른 행렬식과 관절속도 합성 크기, `--wrist`는 회전축과 행렬식을 표시합니다. `--frames`는 각 모드의 36장 프레임(12fps, 3초)을 함께 만듭니다. 영상은 실제 로봇 측정이 아닌 **수식 계산의 시각화**입니다.

MinGW GCC/G++ 또는 이에 준하는 C·C++ 컴파일러를 설치하고 실행 파일과 런타임 DLL이 PATH에서 보이도록 합니다. CLion 번들 MinGW를 사용할 경우 PowerShell에서 해당 `bin` 폴더를 PATH 앞에 추가합니다.

```powershell
gcc c/jacobian.c -o jacobian-c.exe -lm
g++ -std=c++11 cpp/jacobian.cpp -o jacobian-cpp.exe
g++ -std=c++11 cpp/plot_svg.cpp -o plot-svg.exe
./jacobian-c.exe
./jacobian-cpp.exe
./plot-svg.exe
```

세 계산 프로그램은 실행한 현재 디렉터리에 같은 파일명을 쓰므로, 비교할 때는 각각 별도 폴더에서 실행하세요. SVG는 웹 브라우저로 `jacobian.svg`를 열면 됩니다.

|---|---|
| vel.txt | 두 속도 성분, 소수점 아래 네 자리 |
| jac.csv | 2×2 자코비안 원소 |
| sweep.csv | theta2, det, qd1, qd2, qnorm |

## 실험과 검산

스윕은 `theta1=pi/6`으로 고정하고, 각 자세의 베이스에서 손끝으로 향하는 방향에 **0.10 m/s**를 명령합니다. `v=0.10*p/|p|`입니다. 손끝 명령 방향까지 자세별로 갱신합니다.

| theta2 (rad) | det | qd1 (rad/s) | qd2 (rad/s) | qnorm (rad/s) |
|---:|---:|---:|---:|---:|
| 0.7854 | 2.1213 | 0.0636 | -0.1527 | 0.1654 |
| 0.4000 | 1.1683 | 0.1250 | -0.2937 | 0.3193 |
| 0.2000 | 0.5960 | 0.2500 | -0.5844 | 0.6356 |
| 0.1000 | 0.2995 | 0.5000 | -1.1672 | 1.2698 |
| 0.0500 | 0.1499 | 1.0000 | -2.3336 | 2.5388 |
| 0.0200 | 0.0600 | 2.5000 | -5.8334 | 6.3466 |
| 0.0100 | 0.0300 | 5.0000 | -11.6667 | 12.6930 |
| 0.0010 | 0.0030 | 50.0000 | -116.6667 | 126.9296 |

각도를 반으로 줄였을 때 증가는 **근사적으로** 두 배입니다. qnorm은 두 관절속도 벡터의 길이이며 개별 관절속도가 아닙니다. 관절마다 180도/s 한계를 가정하면 **관절 2**가 `theta2≈0.0371384 rad`(2.13도)에서 먼저 한계에 닿습니다.

| 특이 자세 | 결과 |
|---|---|
| 2링크, theta2=0 | 바깥 경계 r=3.5, rank 1 |
| 2링크, theta2=pi | **안쪽 경계** r=0.5, rank 1 |
| 3링크 길이 (2,1.5,1), 각 (pi/6,pi,0) | **영역 내부** r=0.5, rank 1 |

이상적인 평면 3링크의 도달 반지름은 0~4.5입니다. 내부 자세의 자코비안은 `[[0.25,1.25,0.5],[-0.4330,-2.1651,-0.8660]]`이며 세 열이 평행합니다. 관절 제한·충돌·두께를 제외한 모형입니다. 반면 일반 자세 `(0.5236,0.7854,0.3)`에서는 `J=[[-3.4482,-2.4482,-0.9993],[2.0821,0.3500,-0.0382]]`로 rank 2입니다. 비정방 2×3 행렬에는 행렬식 판정을 쓰지 않습니다.

손목의 예시 축은 `z1=(0,0,1)`, `z2=(0,1,0)`, `z3=(sin(beta),0,cos(beta))`입니다. 같은 좌표 기준으로 세운 회전 자코비안의 `abs(det)=abs(sin(beta))`입니다. beta 0.7854, 0.2, 0에서 각각 0.7071, 0.1987, 0이며 마지막 자세에서 첫째·셋째 축이 겹쳐 rank 3→2가 됩니다.

Python의 `fd_check`는 중앙 유한차분(h=1e-6)으로 두 열을 검산합니다. `planar_jacobian`으로 일반 3링크와 접힌 3링크를 비교할 수 있습니다. 세 언어를 실제 빌드·실행해 CSV·텍스트의 일치와 유한차분, 특이 자세, 개별 한계 교차를 확인했습니다.

## 흔한 실점

- 첫째 열에서 첫 링크의 항을 빠뜨리거나 가로 성분의 음수 부호를 놓칩니다.
- 각도 입력을 도 단위로 넣거나 소수 0.5236을 계산 전에 30도로 바꿉니다.
- 일반 Python 리스트에 `@`를 쓰거나 관절별 열의 순서를 바꿉니다.
- 정방이라는 이유만으로 역행렬이 항상 존재한다고 가정합니다.
- 완전 굴곡된 2링크의 안쪽 경계를 내부 특이점으로 부릅니다.
- 관절속도 벡터 크기를 개별 관절속도 한계와 혼동합니다.
