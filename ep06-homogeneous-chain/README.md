# EP.6 — 동차변환 체인·역변환·4×4

`T_AC = T_AB T_BC`로 #258을 풀고, 2D 3×3 동차변환으로 #226을 재계산합니다.

## 기대값

| 항목 | 값 |
|---|---|
| #258 이동 `t_AC` | `(-1.0000, 0.0000, 0.0000)` |
| #258 점 `p_A` | `(-1.0000, 1.0000, 0.0000)` |
| 순서 교환 점 | `(1.0000, 3.0000, 0.0000)` |
| #226 네 꼭짓점 | `(1.0000,0.5000)`, `(1.8660,1.0000)`, `(1.3660,1.8660)`, `(0.5000,1.3660)` |
| 왕복 오차 | `1e-12` 이하 |

## 실행

```bash
python python/htm.py
gcc c/htm.c -o htm.exe -lm && ./htm.exe
g++ -std=c++11 cpp/htm.cpp -o htm.exe && ./htm.exe
python python/visualize.py --frames
```

각 구현은 `chain.csv`에 같은 체인 결과를 씁니다. C++의 `plot_svg.cpp`는 프레임 축을 SVG로 출력합니다.

## 흔한 실점

1. 이동량을 회전하지 않고 따로 더한다.
2. `T_AB T_BC`의 순서를 바꾼다.
3. 역변환 이동 항을 `-t`로만 쓴다. 정답은 `-Rᵀt`다.
