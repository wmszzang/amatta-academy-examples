# EP.13 — 수치 역기구학과 정역학

공식으로 풀리지 않는 팔의 관절각을 **오차를 자코비안으로 되돌리는 반복**(뉴턴-랩슨)으로 구하고, 같은 자코비안을 **전치**해 손끝 힘에서 관절 토크를 구합니다. 길이·속도는 숫자만 쓰고, 힘과 토크에만 뉴턴(N)·뉴턴 미터(N·m)를 붙입니다.

[강의 페이지](https://www.techrraforming.com/academy/cert-prac-numeric-ik-statics) · [실기 연습장](https://www.techrraforming.com/practical?cert=RobotSoftware)

## 입력과 기대값

2링크 팔은 길이 `a = (2.0, 1.5)`, 3링크 팔은 `a = (2.0, 1.5, 1.0)`입니다. 수렴 허용치는 `1e-6`, 반복 상한은 200, 특이 판정 임계는 `|det J| < 1e-12`입니다. 코드 내부 각도는 라디안입니다.

> ⚠️ **반복 횟수의 정의**: 이 저장소와 영상은 **관절각을 실제로 갱신한 횟수**를 반복 횟수로 셉니다. 오차 검사 횟수는 그보다 1 많습니다. #253의 정답은 **갱신 5회 = 오차 검사 6회**입니다. 채점 기준이 어느 쪽을 요구하는지 확인한 뒤 제출하세요.

### 뉴턴-랩슨 (#253)

| 항목 | 값 |
|---|---|
| 입력 | `a=(2, 1.5)`, 목표 `(2.5, 1.5)`, 초기각 `(0.5, 0.5)`, step 1.0 |
| 오차열 | 0.7240 · 0.6149 · 0.07514 · 0.001745 · 1.254e−06 · 5.458e−13 |
| 수렴각 | `(0.0432, 1.1864)` rad — 갱신 5회 |
| FK 검산 | `(2.5000, 1.5000)` |
| 해석해 대조 | 엘보 업 해와 소수 넷째 자리까지 일치 |

초기각을 `(2.0, -1.0)`으로 바꾸면 같은 목표에서 엘보 다운 해 `(1.0376, -1.1864)`에 착지합니다. **초기값이 두 해 중 어느 쪽으로 갈지를 고릅니다.**

step 감쇠 스윕: `1.0 / 0.7 / 0.5 / 0.2` → `5 / 12 / 20 / 61`회. 안정과 속도를 맞바꾸는 손잡이입니다.

### 특이점에서의 폭주와 DLS (#253 확장)

목표 `(3.4, 0.15)`(도달 한계 3.5 바로 안쪽), 초기각 `(0, 0)`은 `det J = 0`이라 무감쇠 뉴턴이 **첫 나눗셈에서 중단**됩니다.

- `(0, 0.001)`로 살짝 비틀면 죽지는 않지만 오차가 `0.1803 → 2.704 → 6.4512`로 튀고 관절각이 `(-43.7348, 112.6212)` rad = `(-2505.8°, 6452.7°)`까지 폭주합니다.
- 그 각의 FK는 `(3.4000, 0.1500)`으로 **정확히 맞습니다.** 래핑하면 `(0.2475, -0.4762)` — 엘보 다운 분기에 우연히 얹힌 것입니다.
- DLS(`λ=0.1`)는 같은 특이 초기값에서 오차가 `0.1803 → 0.09669 → 0.09023 → 0.02635 → 0.00266 → 1.905e−04 → 1.292e−05 → 8.726e−07`로 단조 감소하며 **7회**에 `(-0.1593, 0.4762)`로 수렴합니다. FK 검산 `(3.4000, 0.1500)`.

λ 스윕: `0.01 / 0.05 / 0.1 / 0.3 / 1.0` → `8 / 5 / 7 / 20 / 140`회. `λ=0.01`은 빠르지만 중간에 오차가 **5.2898**까지 튑니다. `λ=0`은 `JJᵀ`가 특이해 무감쇠와 똑같이 죽습니다.

### 의사역행렬과 널공간

`a=(2, 1.5, 1.0)`, `θ=(0.5, 0.5, 0.5)`에서 `J`는 2행 3열입니다.

```
J = [ -3.2186  -2.2597  -0.9975 ]
    [  2.6364   0.8812   0.0707 ]
```

검산 요령: **평면 사슬 자코비안의 첫 열은 언제나 `(-y, x)`** 입니다. FK가 `(2.6364, 3.2186)`이므로 첫 열 `(-3.2186, 2.6364)`와 정확히 대응합니다.

`ẋ = (0, 1)`에 대한 최소노름해는 `q̇ = (0.5895, -0.5820, -0.5837)`, 노름 1.0134이고 `J q̇ = (0, 1)`로 복원됩니다. 널공간 방향은 `n = (0.1796, -0.6000, 0.7796)`이며 `J n = (0, 0)`입니다.

| α | ‖q̇ + αn‖ | 손끝 속도 |
|---:|---:|---|
| 0.0 | 1.0134 | (0, 1) |
| 0.5 | 1.1300 | (0, 1) |
| 1.0 | 1.4237 | (0, 1) |

손끝 일은 같은데 관절만 더 바쁜 답이 무한히 있고, 의사역행렬은 그중 가장 게으른 답을 줍니다.

### 정역학 (#260)

`θ=(0.5, 0.5)`에서 `J = [[-2.2211, -1.2622], [2.5656, 0.8105]]`, `det J = 1.4383 = a₁a₂sin θ₂`입니다.

- `F = (3, -1)` N → **`τ = JᵀF = (-9.2288, -4.5971)` N·m**
- 전치를 빠뜨리면 `J·F = (-5.4010, 6.8864)` — 부호까지 다른 **완전한 오답**입니다. 루브릭이 그대로 경고합니다.
- 가상일 검증: `q̇ = (0.3, -0.7)`일 때 `F·ẋ = τ·q̇ = 0.4493136496`.

중력 보상(`m=(3, 2)` kg, 무게중심 = 링크 중앙, `g = 9.81`):

| 자세 | τ_g (N·m) |
|---|---|
| `(0.5, 0.5)` | (68.2141, 7.9505) |
| `(0, 0)` 수평 | (83.3850, 14.7150) — 최대 |
| `(π/2, 0)` 수직 | (0, 0) |
| + 2 kg 페이로드 유지 | (50.3374, 15.9011) → 합계 (118.5516, 23.8516) |

닫힌형과 링크별 무게중심 자코비안 합산 `Σ Jc,iᵀ(0, -m_i g)`이 소수 넷째 자리까지 일치하는지 코드가 함께 출력합니다. **질량이 들어온 순간부터 이 계산은 동역학 소관입니다.**

### 경계 — 지지 다각형 정적 안정 여유 (#484)

반시계(CCW) 규약에서 각 변 `A→B`에 대해 `d = cross(B-A, P-A) / |B-A|`를 재고, **최솟값이 안정 여유**입니다. 한 변에서라도 음수면 밖, 불안정입니다.

| 다각형 | 투영점 | 판정 | 여유 |
|---|---|---|---:|
| 한 변 1 정사각형 | (0.5, 0.5) | 안정 | 0.5 |
| 한 변 1 정사각형 | (0.9, 0.5) | 안정 | 0.1 |
| 한 변 1 정사각형 | (1.2, 0.5) | 불안정 | −0.2 |
| 삼각형 (0,0)(2,0)(1,1.5) | (1.0, 0.4) | 안정 | 0.4 |

## 흔한 실점

- **전치를 빠뜨림**: 역기구학에 쓰던 습관으로 `J·F`를 계산하면 부호까지 틀립니다. 힘은 반드시 `JᵀF`입니다.
- **관절각 래핑 누락**: 폭주해도 FK는 맞을 수 있습니다. `[-π, π]`로 접지 않으면 답처럼 보이는 오답이 됩니다.
- **반복 횟수 정의 혼동**: 갱신 5회와 오차 검사 6회를 구분해 명시하세요.
- **특이 자세를 나눗셈으로 통과시킴**: `|det J|`를 매 걸음 감시하고 임계 아래면 DLS로 갈아탑니다.
- **의사역행렬을 '역행렬의 근사'로 설명**: 무수한 해 중 **최소노름해**를 고르는 규칙입니다.
