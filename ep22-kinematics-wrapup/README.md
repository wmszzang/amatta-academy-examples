## 실행

Python 3와 numpy, matplotlib가 필요합니다.

```sh
python -m pip install numpy matplotlib
python python/kin.py out/python
python -m tests.check
gcc -std=c11 c/kin.c -o out/kin-c.exe -lm
g++ -std=c++11 cpp/kin.cpp -o out/kin-cpp.exe
out/kin-c.exe out/c
out/kin-cpp.exe out/cpp
python -m tests.parity
python python/visualize.py --csv out/python --frames --out out
```

처음 실행 전에 `out/python`, `out/c`, `out/cpp` 폴더를 만드세요. C와 C++는 같은 알고리즘을 각 언어로 컴파일하며 표준 수학 라이브러리만 사용합니다. C++ 코드는 C와 호환되는 `Pt`, `Pose`, `Joint` 구조체로 구성했습니다.

## 코드와 산출물

`python/kin.py`가 통합 진입점입니다. `transform`, `fk`, `ik`, `jacobian`, `rotation`, `path`, `mobile`, `calib+camera`의 **8개 기능 묶음**이며 보정 묶음은 두 파일로 나눠 **9개 모듈 파일**입니다. 앞 편에서 다룬 변환·팔 기구학·회전 표현·경로·이동로봇·보정을 같은 입력 체계로 실행합니다.

`calib.py`는 제출용 SVD와 독립 검산용 2D 간편식을 모두 제공합니다. C/C++의 SVD는 2×2 교차공분산의 오른쪽 특이벡터를 구하고 `U=HV/Σ`로 구성합니다. 두 특이값이 0이 아닌 대응점이 대상이며 퇴화 입력은 오류로 구분합니다. 반사 보정을 실행합니다.

`wheels.csv`, `odom.csv`, `steer.csv`, `arc_path.csv`, `jointlerp_gap.csv`, `calib.txt`, `camera.csv`, `rejudge.csv`를 생성합니다. 오도메트리는 시작점 포함 41행입니다. 내부 각도는 라디안이고 `arc_path.csv`의 angle/th1/th2 및 정합 텍스트의 각도만 도입니다. 출력에서만 소수 넷째 자리로 반올림합니다.

`path.trapezoid`는 거리·최고속도·가속도 한도를 인자로 받고 짧은 거리의 삼각형 속도 프로파일도 처리합니다. 한도 수치를 지문에 임의로 추가하지 않습니다. `cubic_approach`는 정지에서 정지로 가는 관절 접근 구간이며 손끝 원호를 보장하지 않습니다.

## 실험과 흔한 실점

중점각 사용 여부를 바꿔 오도메트리 차이를 확인하세요. 바퀴 출력 순서, `tan`과 `sin`, 도와 라디안, 트레드와 절반 트레드를 섞지 마세요. #240의 각도 균등 분할은 원문 조건상 맞습니다. 가감속을 추가하면 시간별 호길이를 따로 구합니다. 도달 불가는 `None`/reachable=false로 구분하고 제출 표기는 `UNREACHABLE`입니다. 카메라는 깊이·시차가 양수인지 나눗셈 전에 검사합니다.
